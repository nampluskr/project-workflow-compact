# project-workflow-compact

프로젝트를 시작할 때 참고하고 활용할 문서 기반 레포다. 새 프로젝트를 열 때마다 여기서 가져다 쓰고, 새 버전을 시작할 때도 참고한다. 읽는 쪽에는 AI 에이전트도 포함된다. 이 레포가 무엇을 왜 하고 어떤 원칙을 지키는지는 [INTENT.md](INTENT.md)에 있다.

## 읽는 순서

README에서 시작해 [docs/WORKFLOW.md](docs/WORKFLOW.md), [docs/DOCUMENTS.md](docs/DOCUMENTS.md), [docs/templates/](docs/templates/) 순서로 읽는다.

- [docs/WORKFLOW.md](docs/WORKFLOW.md) — 신규 시작에서 다음 버전까지의 흐름.
- [docs/DOCUMENTS.md](docs/DOCUMENTS.md) — 문서별 절 구성과 작성 기준.
- [docs/templates/](docs/templates/) — 문서별 빈 양식.

## 예시

이 레포의 [specs/v0.1/](specs/v0.1/)이 위 가이드를 따라 쓴 첫 예시다.

## 새 프로젝트를 시작하려면

[docs/WORKFLOW.md](docs/WORKFLOW.md)의 "1. 신규 시작"부터 읽는다.

## 이 레포의 다른 폴더

- `docs/HERDR-*.md`는 이 레포를 만들 때의 운영 기록이며 가이드가 아니다.
- 원본 project-workflow(v0.2)는 GitHub `nampluskr/project-workflow`에 있다.
